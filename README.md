# Mentor Service
***
Сервис, предоставляющий менторский функционал

### Основная информация

Сервис предоставляет возможность для управления менторами, гарантированными ревью и ценами на них. Менторы имеют возможность сами выбирать цены на свои ревью

### Технологический стек

- Java 21
- Spring Boot 3
- Spring Data JDBC
- PostgresSQL
- Liquibase
